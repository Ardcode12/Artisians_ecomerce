Seller Order-Confirmation Call System

When a buyer places an order on GeM / ONDC or another portal, the backend automatically calls the seller via Twilio to confirm or reject the order — in the seller's preferred language.

Backend API Endpoints

POST /api/calls/trigger Trigger seller confirmation call
GET /api/calls/{call_id} Poll call status
GET /api/calls List all calls
POST /api/calls/webhook/voice TwiML voice script (Twilio webhook)
POST /api/calls/webhook/gather DTMF input handler (1=confirm, 2=reject)
POST /api/calls/webhook/status Twilio call-status callback
